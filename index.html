使用说明

这是一个单文件、零依赖、纯本地的 DXF 查看器 / 测量 / 绘图 / 编辑工具。双击 HTML 即可在浏览器中打开，不需要服务器、不需要联网、不需要安装任何插件。DXF 文件只在你的浏览器里解析，不会上传。

两种使用方式

1. 直接把 .dxf 拖进窗口，或用顶部按钮选择文件。
2. 用附带的 dxf2html.js 把某个 DXF 内嵌成独立网页，双击即直接显示图纸，无需再选文件。
3. 不打开任何文件，直接点左侧绘图工具，也能从空白图纸开始画。

视图操作

滚轮 = 以光标为中心缩放；浏览模式下左键拖拽 = 平移；F = 适应窗口；G = 网格；Esc = 结束当前工具并清除选择。
在其它工具中，用鼠标中键拖拽或按住空格 + 左键拖拽平移，右键等于回车（结束连续命令）。

测量

左侧「测量」组：距离、连续距离、夹角、面积 / 周长、半径 / 直径 / 周长、点坐标、快速测量（悬停即显示对象长度 / 面积 / 半径）。测量标注直接画在图上，右侧列出全部记录，可单条删除、整体清除或导出 CSV。测量时自动启用对象捕捉：端点、中点、圆心、象限点、交点、垂足、最近点（F3 开关），另有栅格捕捉与正交（F8）。

绘图

直线（可连续）、多段线（回车结束 / C 闭合）、矩形、圆（可输入半径回车）、三点圆弧、点、文字（命令条输入内容后回车，再单击放置）。新对象的图层、颜色（ACI / 真彩色）、线宽、字高在左侧「绘图设置」里选。圆和直线也支持输入长度 / 半径后回车精确定位。

编辑与保存

先用「选择」工具点选或框选对象（Shift 加选，Ctrl+A 全选），再执行移动、复制、旋转、缩放、镜像、删除；也可拖动已选中对象直接移动。右侧「对象属性」可批量改图层、颜色、线宽。所有编辑都作用于原始 DXF 组码，Ctrl+Z / Ctrl+Y 撤销重做，Ctrl+S 或「保存 DXF」把结果另存为新的 ASCII DXF（保留原文件 HEADER / TABLES / BLOCKS / OBJECTS 等段）。

保存格式：「保存 DXF」右侧的下拉框可选 2018 / 2013 / 2010 / 2007 / 2000，默认与原图同版本。若原图是 2018 而你只有 AutoCAD 2013，选「AutoCAD 2013」即可。跨版本导出时，视觉样式、材质、注释比例等与版本强相关的对象会被重置为默认值（AutoCAD 会自动重建），图元、图层、块、文字不受影响。R12/R14 老图缺少句柄与子类标记，无法直接升级到新版本，会提示你先在 CAD 里另存为 2000 以上。

常用快捷键

V 选择 · H 平移 · Q 快测 · D 距离 · N 连续 · K 角度 · J 面积 · R 半径 · I 坐标 · L 直线 · P 多段线 · B 矩形 · C 圆 · A 圆弧 · O 点 · T 文字 · M 移动 · Y 复制 · U 旋转 · S 缩放 · X 镜像 · E 删除。
也可以在命令条里输入 CAD 风格命令：PL、REC、DI、AA、CO、RO、SC、MI 等。

颜色还原规则

按 DXF 优先级解析：420 真彩色 > 62 ACI 索引色 > 随层 ByLayer（含图层真彩色）> 随块 ByBlock（继承 INSERT 链）。ACI 采用 AutoCAD 2020 官方 256 色表。7 号色（白/黑）会随背景自动反色，深色画布下与 CAD 模型空间一致。负 ACI 色（图层关闭）仍按原色显示。

支持的 DXF 对象

LINE、LWPOLYLINE（含 bulge 圆弧）、POLYLINE / VERTEX、CIRCLE、ARC、ELLIPSE、SPLINE（NURBS）、POINT、SOLID、TRACE、3DFACE、TEXT、MTEXT、ATTRIB、ATTDEF、INSERT（嵌套块 / 阵列 / ByBlock 继承）、DIMENSION（匿名块）、HATCH（实体填充与图案线）、LEADER、MLINE、XLINE、RAY、IMAGE / WIPEOUT / VIEWPORT 边框。

已知边界

仅支持 ASCII DXF；二进制 DXF 请在 CAD 中另存为 ASCII。渲染为二维俯视投影，3DSOLID / REGION / BODY 等 ACIS 实体、光栅图片像素数据、代理对象无法还原，会在左侧「未渲染类型」中明确列出。文字 / 标注 / 填充的镜像与缩放在复杂实体上为近似结果；导出的 DXF 文本为 UTF-8 编码，旧版 CAD 若原本使用 GBK 代码页，中文可能需要重新指定代码页。
